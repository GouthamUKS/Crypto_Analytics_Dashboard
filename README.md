# Banking Dashboard

React 18 banking dashboard built to Barclays UI engineering standards.

Live: https://banking-dashboard-ten.vercel.app/

Lighthouse: 99+. WCAG 2.1 AAA compliant.

---

## Features

- Transaction management and account overview
- Currency tracking
- Authentication flow
- High contrast mode and keyboard navigation
- Redux Toolkit with memoised selectors for state management

---

## Tech stack

- React 18
- TypeScript
- Redux Toolkit
- Tailwind CSS
- Vercel

---

## Accessibility

WCAG 2.1 AAA compliant. Semantic HTML throughout, full keyboard navigation, high contrast mode, and screen reader support.

---

## Local setup

```sh
git clone https://github.com/GouthamUKS/Banking_Dashboard_test.git
cd Banking_Dashboard_test/frontend
npm install
npm run dev
```
